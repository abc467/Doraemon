这份文案包用于制作面向领导的汇报 PPT。汇报重点不是代码细节，而是突出：

- 整套清洁机器人系统架构由我从零设计并落地。
- 前端工程和后端核心链路均由我主导完成。
- 系统功能完整，已经覆盖清洁机器人从地图、规划、执行、感知、回充到管理的完整闭环。
- 重点展示四个先进模块：全覆盖路径规划、导航与智能避障、视觉感知、自动回充与补给。
- 根据真实场景持续做了大量细节优化，让系统从研发功能走向现场可用。

建议 PPT 控制在 13 页左右，适合 10-15 分钟汇报。

## 第 4 页：整体系统架构

### 页面标题

整体系统架构：前端层 + 五层机器人能力架构

### 页面展示文字

自上而下分为六个层面：

- Frontend / UI Layer：地图管理、区域编辑、任务创建、调度配置、状态监控、回充标定
- Task Layer：任务编排、任务调度、任务状态机、断点续扫、回充策略
- Plan Layer：区域生成、全覆盖路径规划、路径版本、清洁模式 profile
- Execute Layer：路径执行、分段 CONNECT/FOLLOW、暂停继续、清扫机构联动
- Navigation Layer：全局导航、局部控制、智能避障、回桩/离桩动作
- Hardware Layer：底盘、传感器、刷盘、水泵、吸水、吸尘、电池、充电座

### 讲解稿

整个系统我按六层架构设计。最上面是前端层，负责把复杂的机器人能力变成用户能操作的界面。下面是任务层，负责业务层面的任务编排、调度、断点续扫和回充策略。规划层负责把清扫区域转化为可执行的覆盖路径。执行层负责按照路径分段执行，并联动清扫机构。导航层负责全局路径、局部运动、避障和回桩动作。最底层是硬件层，包括底盘、传感器、清扫机构、电池和充电座。这样的分层设计让各模块职责清晰，也便于后续扩展和维护。

### 作图/排版建议

- 画一张纵向分层架构图。

- 右侧可以标注这一层“解决什么问题”：
  - 前端层：可操作
  - 任务层：可管理
  - 规划层：可规划
  - 执行层：可清扫
  - 导航层：可安全移动

## 第 5 页：完整功能闭环

### 页面标题

功能闭环：从建图定位到自动回充

### 页面展示文字

完整流程：

1. 建图定位：建立现场地图，确定机器人位置
2. 区域配置：划分清扫区域、禁行区、虚拟墙
3. 路径规划：自动生成全覆盖清扫路径
4. 任务创建：绑定区域、模式、频次和执行策略
5. 任务执行：导航移动并联动清扫机构
6. 状态监控：展示进度、电量、异常和任务状态
7. 自动回充：任务结束或低电量自动回桩补给
8. 续扫/完成：补能后继续任务或结束任务

### 讲解稿

这套系统已经形成了完整的业务闭环。首先机器人可以完成建图和定位；然后在地图上配置清扫区域、禁行区和虚拟墙；系统会基于区域自动生成覆盖路径；再通过前端创建任务，设置清扫模式和调度策略；任务执行时，机器人按照路径移动，同时控制刷盘、水泵、吸水和吸尘等清扫机构；运行过程中可以监控任务进度和设备状态；当任务完成或电量不足时，机器人可以自动回桩补给，必要时再继续未完成的任务。这个闭环是清洁机器人从研发功能走向实际应用的关键。

### 作图/排版建议

- 用环形流程图，中心写“自主清洁闭环”。
- 环形节点按上面 8 步排列。
- 自动回充到续扫之间可以用醒目的箭头，突出长期自主运行能力。

## 第 8 页：重点模块一：全覆盖路径规划

### 页面标题

全覆盖路径规划：从区域自动生成清扫路线

### 页面展示文字

- 根据清扫区域自动生成覆盖路径
- 支持禁行区、虚拟墙、安全距离和不同清扫模式
- 支持路径版本管理和 profile 参数配置
- 将人工经验路线升级为算法自动规划路线

### 讲解稿

全覆盖路径规划是我认为比较先进、也最能体现清洁机器人价值的模块之一。传统方式可能需要人工画路线，效率低，而且很难保证一致性。我实现的是从清扫区域自动生成覆盖路径，系统会考虑区域边界、禁行区、虚拟墙、安全距离、清扫宽度和转弯策略。不同清洁模式可以对应不同规划参数，生成的路径也可以进行版本管理。这样现场人员只需要配置区域，系统就可以自动生成可执行的清扫路线。

### 作图/排版建议

- 左右对比图：
  - 左侧：人工画线/经验路线，标注“不稳定、难复用”。
  - 右侧：区域自动生成覆盖路径，标注“自动、可复用、可管理”。
- 最好配一张地图上有清扫路径的截图。
- 可用三点价值总结：覆盖完整、配置高效、路线可追溯。

## 第 9 页：重点模块二：导航与智能避障

### 页面标题

导航与智能避障：让机器人在真实现场安全移动

### 页面展示文字

- 全局导航：负责从当前位置找到可行路径
- 局部控制：负责平滑跟踪路径并实时调整运动
- 多源避障：融合激光、深度障碍、禁行区、虚拟墙
- 恢复机制：遇到局部异常时进行恢复和重试

### 讲解稿

导航与避障模块解决的是机器人“怎么安全地走”的问题。系统中既有全局导航，负责找到从当前位置到目标点的大方向路径；也有局部控制，负责在真实运动过程中平滑跟踪路径，并根据障碍物实时调整。避障上，不只是依赖单一传感器，而是融合激光、深度障碍、禁行区和虚拟墙等信息，形成统一的安全约束。这样机器人既能按规划路径清扫，也能适应真实现场的障碍和环境变化。

### 作图/排版建议

- 用“导航决策流”图：
  - 目标点/清扫路径 -> 全局规划 -> 局部控制 -> 底盘运动
  - 旁边接入：激光、视觉深度、禁行区、虚拟墙
- 可用红色区域表示障碍或禁行区，绿色线表示安全路径。

## 第 10 页：重点模块三：视觉感知

### 页面标题

视觉感知：补强真实清洁场景下的障碍识别

### 页面展示文字

- 接入深度相机/视觉感知能力，输出障碍物信息
- 补充激光雷达在低矮、近距离、复杂障碍上的感知不足
- 感知结果参与导航避障，提高现场适应性
- 让系统从单一雷达导航升级为多传感器融合感知

### 讲解稿

清洁机器人面对的现场环境比较复杂，单靠激光雷达有时不足以覆盖所有障碍情况，比如低矮障碍、近距离障碍或一些复杂结构。视觉感知模块通过深度相机补充环境信息，识别前方或侧方的障碍物，并把障碍信息接入导航避障系统。这样可以提升机器人在真实场景中的安全性和适应性，也让整个系统从单一传感器导航升级为多传感器融合感知。

### 作图/排版建议

- 画“多传感器融合”示意图：
  - 激光雷达
  - 深度相机
  - 里程计/IMU
  - 地图约束
  - 汇聚到导航避障模块
- 如果有深度点云或障碍检测截图，可以放右侧。
