## 第 3 页：整体系统架构

### 页面标题

整体系统架构：前端层 + 五层机器人能力架构

### 页面展示文字

- Frontend / UI Layer：地图管理、区域编辑、任务创建、调度配置、状态监控
- Task Layer：任务编排、状态机、断点续扫、调度策略、回充策略
- Plan Layer：区域生成、全覆盖路径规划、路径版本、清洁模式配置
- Execute Layer：路径分段执行、暂停继续、清扫机构联动、进度跟踪
- Navigation Layer：全局导航、局部控制、智能避障、回桩/离桩动作
- Hardware Layer：底盘、传感器、清洁机构、电池、充电座

### 讲解稿

系统采用分层架构。最上层是前端，负责把复杂机器人能力变成可操作界面。任务层负责清扫任务的业务编排，比如调度、断点续扫和回充策略。规划层把清扫区域转成路径。执行层按照路径控制机器人移动和清扫机构。导航层负责路径跟踪和避障。硬件层负责底盘、传感器、清洁机构、电池和充电座等设备接入。这样的分层让每个模块职责清晰，也方便后续扩展。

### 作图/排版建议

- 画纵向六层架构图。
- 每层右侧加一句价值：
  - 前端层：可操作

  - 规划层：可生成路线
  - 执行层：可执行清扫
  - 导航层：可安全移动
  - 硬件层：可控制设备

## 第 4 页：核心业务闭环

### 页面标题

核心业务闭环：从地图到清扫，再到自动回充

### 页面展示文字

完整闭环：

建图定位 -> 区域配置 -> 覆盖路径规划 -> 任务创建 -> 清扫执行 -> 状态监控 -> 自动回充 -> 续扫/完成

配套管理：

- 地图、区域、路径、任务、调度、清洁模式统一管理
- 任务执行前进行系统就绪检查
- 运行中持续跟踪进度、电量、异常和设备状态

### 讲解稿

这套系统的核心价值，是形成了从地图到任务、从任务到执行、从执行到回充的完整闭环。操作人员先完成地图和区域配置，系统自动生成清扫路径，再创建任务并启动执行。执行过程中可以查看进度、状态和异常。任务结束或电量不足时，机器人可以进入回充补给流程，必要时再继续未完成任务。这个闭环让机器人从“能动”变成“能完成清洁作业”。

### 作图/排版建议

- 用一张环形流程图表现闭环。
- 左下角放“数据库资产管理”，右下角放“系统就绪检查”，作为闭环支撑能力。

### 页面标题

任务与执行：让路径真正变成清扫作业

### 页面展示文字

## 第 7 页：重点模块一：全覆盖路径规划

### 页面标题

全覆盖路径规划：区域自动生成清扫路线

### 页面展示文字

实现能力：

- 根据清扫区域自动生成覆盖路径
- 支持禁行区、虚拟墙、安全距离、清洁模式和路径版本
- 支持不同 profile，对应不同清扫策略和规划参数

亮点价值：

- 减少人工画路线
- 提升覆盖完整性和路线一致性
- 让清扫路线可复用、可管理、可追溯

### 讲解稿

全覆盖路径规划是系统中非常关键的先进模块。它的目标是把“要扫哪里”自动转化为“怎么扫”。现场只需要配置清扫区域，系统就可以结合禁行区、虚拟墙、安全距离和清洁模式自动生成覆盖路径。相比人工画路线，这种方式更稳定、更可复用，也更适合后续规模化管理。

### 作图/排版建议

- 左右对比：
  - 左：人工路线，标注“效率低、难复用”。
  - 右：自动覆盖路径，标注“自动生成、可管理、可追溯”。
- 如果有路径规划截图，放在页面中心作为主图。

导航与智能避障：真实现场中的安全移动能力

### 页面展示文字

实现能力：

## 第 9 页：重点模块三：视觉感知

### 页面标题

视觉感知：补强复杂清洁场景下的障碍识别

### 页面展示文字

实现能力：

- 接入深度相机/视觉感知，输出障碍物信息
- 补充激光雷达在低矮、近距离、复杂障碍上的感知不足
- 感知结果参与导航避障

亮点价值：

- 从单一雷达导航升级为多传感器融合感知
- 提升机器人对真实场景的安全性和适应性

### 讲解稿

清洁机器人面对的现场环境比较复杂，单一激光雷达并不能覆盖所有障碍情况。视觉感知模块通过深度相机补充环境信息，特别是低矮障碍、近距离障碍和复杂结构。感知结果接入导航避障系统后，可以增强机器人对真实场景的适应能力，也提升了整体运行安全性。

### 作图/排版建议

- 画多传感器融合示意图：
  - 激光雷达
  - 深度相机
  - 里程计/IMU
  - 地图约束
  - 汇入导航避障模块
- 如果有深度点云或障碍检测截图，作为右侧主图。

## 第 10 页：重点模块四：自动回充与补给

### 页面标题

自动回充与补给：支撑长时间自主运行

### 页面展示文字

实现能力：

- 任务结束或低电量自动回桩
- 预对接、精准对接、充电、补水/排污
- 回充标定与对接质量判断
- 充满后续扫或结束任务

亮点价值：

- 减少人工介入
- 支撑机器人长时间自主作业
- 让清洁机器人从“单次任务”走向“持续运营”

### 讲解稿

自动回充与补给是机器人长期自主运行的关键。系统可以在任务完成或低电量时自动触发回桩流程，包含预对接、精准对接、充电、补水和排污等环节。它还支持回充标定和对接质量判断，便于现场调试和维护。这个模块让机器人不只是完成一次清扫，而是具备持续运营的能力。

### 作图/排版建议

- 画流程图：
  - 低电/任务完成 -> 回桩导航 -> 预对接 -> 精准对接 -> 充电/补给 -> 续扫/完成

## 去重后的表达原则

制作 PPT 时建议遵守以下原则：

- “从零设计”“独立完成前端”“打通主链路”只在第 1-3 页集中强调。
- 第 4 页以后重点讲模块本身，不再重复完整闭环。
- 每个重点模块只讲三件事：实现了什么、解决了什么、为什么有价值。
- “现场细节优化”只概括，不编造具体案例。
- 技术名词作为支撑，不作为主角。
